# Avoid The Vacuum - Android Game 🐱🧹

A fun mini-game built in Kotlin using Android Studio where your cat avoids falling vacuum cleaners!

## 🕹️ Gameplay Features
- 3-lane road
- Player-controlled cat (left/right movement)
- Falling vacuum cleaners (obstacles)
- 3 lives
- Toast + vibration on collision
- Game over screen

## 📱 Tech Stack
- Kotlin
- Android SDK
- RelativeLayout UI
- Handler & Runnable game loop

## 🎮 Controls
- Tap left or right buttons to move
- Avoid the vacuum robots or lose a life!

## 🚀 How to Run
1. Clone this repo
2. Open in Android Studio
3. Run on emulator or Android device (tested on Galaxy A51)
